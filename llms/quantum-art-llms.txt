# Quantum Art

> Quantum Art is a quantum computing company building scalable trapped-ion quantum computers for commercial applications. Its Quantum-as-a-Service (QaaS) platform exposes a Qiskit-provider-compatible REST API for listing backends, submitting and managing quantum jobs, and retrieving results, alongside account, task, artifact, and administration management.

## Key operations

- List backends: GET /provider/backends
- Backend details: GET /provider/backends/{backend_name}
- Submit job: POST /provider/jobs (backend + QASM circuit + shots)
- Job status: GET /provider/jobs/{job_id}
- Job result: GET /provider/jobs/{job_id}/result
- Cancel job: DELETE /provider/jobs/{job_id}
- Tasks: POST/GET /api/tasks, GET /api/tasks/{task_id}, results/inputs download
- Auth: POST /auth/register, POST /auth/login (+ MFA), API key at /api/profile/api-key

## Authentication

- Bearer token (Authorization: Bearer <token>) via /auth/login (optional MFA), or a per-account API key managed at /api/profile/api-key.
